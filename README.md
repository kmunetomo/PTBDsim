# PTBDsim

X線透視下PTBD（経皮経肝胆道ドレナージ）で、2Dの透視像から3Dの肝内胆管の位置を推測する感覚を、
放射線科専攻医がスマホ（横持ち）で自習するためのWebアプリ（試作版）。

- 模式解剖のみ。患者データは含まない
- 仕様は `docs/requirements.md`（Claude Docs版の要件定義書からの書き出し）

## 開き方

`index.html` をブラウザで開くだけで動く（three.js r128 をCDNから読み込むためネット接続が必要）。

傾き操作（ジャイロ）は、HTTPSで配信したページを直接開いたときのみ動作する想定（未検証）。

## ファイル

| パス | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JSを1ファイルに格納） |
| `docs/requirements.md` | 要件定義書 |

## 座標系（開発メモ）

- 計算用の座標は cm 単位で x＝患者の左、y＝腹側、z＝頭側（左手系）
- 透視はこの座標のまま描画し、放射線科の表示規約（患者の右が画面の左）になる
- 3D答え合わせは x 軸を反転して実際の左右に直して描画している
