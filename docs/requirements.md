# PTBD穿刺トレーニングアプリ 要件定義書

Oct 24, 2026 · @Kazuaki Munetomo

## 1. 目的と背景

放射線科専攻医が、X線透視下PTBDで「2Dの透視像から3Dの肝内胆管の位置を推測する」感覚を、被ばくなしにスマホで自習できるWebアプリを作る。

- 透視下穿刺は、投影像と体表の目印（肋骨・椎体）を頼りに3Dの胆管へ針を進める手技であり、その空間把握が難しい
- 実症例で経験できる数は限られ、練習のための透視は被ばくを伴う
- 本アプリの目的は空間イメージの形成であり、針を持つ手の感覚の訓練は対象外とする（将来、影絵式の実物模型で補う）

## 2. 対象者と利用場面

専攻医が指導医なしで1人で使うため、操作の分かりやすさと自動の答え合わせが要件の中心になる。

| 項目 | 内容 |
| --- | --- |
| 対象者 | 放射線科専攻医（PTBD未経験〜数例程度） |
| 利用場面 | 各自の自習（指導医不在を前提） |
| 端末 | スマホのWebブラウザ（インストール不要） |
| 学習目標 | 刺入点・刺入方向と胆管の立体的な位置関係を、透視像と斜位から推測できる |

## 3. スコープ

初版は模式的な1症例（すべての胆管が拡張・造影済み）で「造影済み胆管を狙う」練習に絞り、症例選択・実データ対応・成績機能は将来版に回す。

| 項目 | 初版（1か月） | 将来版 |
| --- | --- | --- |
| 解剖 | 模式的な肝・胆管・肋骨・椎体の1症例（3Dのみ胸骨・肋軟骨も表示） | 実患者CT由来（匿名化、Claude Codeへ移行して開発）、複数症例 |
| 胆管 | すべて拡張し、造影済みで描出。太さは調整可 | 解剖変異 |
| 症例選択 | なし（固定の1症例） | ルート・難易度・症例を選ぶ画面 |
| 穿刺ルート | 刺入点を自由に選べるため、右肋間・心窩部のどちらからも刺せる | ― |
| 練習モード | A：造影済み胆管を狙う、斜位での位置確認 | B：造影しながら抜去して胆管を探す |
| 補助表示 | ターゲット、ガイド線 | ― |
| フィードバック | 3D答え合わせ、針と中枢側胆管の角度、ターゲットまでの距離 | 成績（穿刺回数・仮想透視時間）、合併症警告（門脈・肝動脈の通過、経胸腔穿刺）、解説文 |
| 胸腔（肺底・横隔膜） | なし | 必要になれば検討 |
| 呼吸性移動 | なし | 必要になれば検討 |
| 配布方法 | 決めない（Claudeの公開ページで動作確認） | 後で決める（傾き操作にはHTTPS配信が条件） |
| 実物連携 | ― | 同じ胆管形状を3Dプリントし影絵式模型に流用 |

## 4. 機能要件（初版）

初版の機能はF1〜F11の11個で、10/24時点ですべて試作版に実装済み。

| ID | 機能 | 内容 |
| --- | --- | --- |
| F1 | 仮想透視画面 | 点線源からの投影（管球〜回転中心75 cm、管球〜検出器115 cm）。表示するのは造影済み胆管・針・肋骨・椎体・肝輪郭（うっすら）。骨は背側ほど濃く、腹側ほど淡く写す（濃淡差50%で固定）。門脈・肝動脈は表示しない |
| F2 | C-arm角度変更 | 正面から左右とも90°まで。スライダーは1°刻み、ボタンは5°刻み |
| F3 | 刺入点の選択 | プリセット（右肋間・心窩部）、透視画像のタップ、1 cm刻みの微調整（頭側／尾側、体表に沿った周方向）。微調整では針の角度を保持 |
| F4 | 針の角度設定 | スライダー（水平面の振り・頭尾方向）を標準とする。傾き操作は実装済みだが、HTTPSで直接開いたときのみ動作（未検証） |
| F5 | 針の前進・後退 | スライダーで深さを動かす。肋骨に当たるとそこで止まる |
| F6 | 穿刺判定 | 胆管内（枝名）／肝実質内／肝外を表示。胆管内では針と中枢側胆管のなす角（0°＝肝門側へまっすぐ、90°＝直交）も表示 |
| F7 | ターゲット | 選んだ枝（B2〜B8）の末梢寄り（枝の75%地点）に球を置く。直径5〜30 mm（初期7 mm）。透視では琥珀色の円で補助表示。刺入点プリセットで推奨枝に切替（右肋間→B6、心窩部→B3） |
| F8 | ガイド線 | 点線で表示し、それぞれON／OFF。刺入点→ターゲット中心、針先からの延長線 |
| F9 | 胆管の太さ | 末梢枝の径2〜12 mm（初期6 mm）。全枝を同じ比率で拡縮し、判定にも反映 |
| F10 | 3D答え合わせ | 肝・胆管・門脈・肝動脈・骨・胸骨／肋軟骨・針・X線の向き・ターゲット・ガイド線を表示。方向ラベル（R／L／頭／腹）付き。指で回転・拡大。結果パネルはタップで閉じる |
| F11 | やり直し | 針を抜いて同じ症例に再挑戦する |

## 5. 画面構成と操作フロー

初版の画面は「穿刺」「答え合わせ」の2つ（症例選択は将来版）で、横持ちで使い、1回の練習は次の順に進む。

1. 横持ちで開く（左＝C-arm・胆管の太さ・ターゲット・ガイド線、中央＝透視、右＝刺入点と針）
2. 刺入点をプリセットかタップで選び、必要なら1 cm刻みで微調整する
3. 必要に応じてターゲットとガイド線を表示する
4. スライダーで針の角度を決める
5. C-armを回して、針の向きと胆管の前後関係を確認する（必要なら4に戻る）
6. 針を進め、判定（胆管内か、中枢側胆管との角度）を見る
7. 3D答え合わせで、針の軌跡と胆管・血管・骨の位置関係を確認する
8. 針を抜いて再挑戦する

## 6. 非機能要件

- **動作環境**：iPhoneのSafari、AndroidのChromeで動くこと。アプリのインストールは不要
- **画面の向き**：横持ちで固定
- **配信**：方法は後で決める。ただしiPhoneで傾きセンサーを使うにはHTTPS配信が必要
- **構成**：初版は1つのHTMLファイルで完結させ、そのままClaude Codeへ移行できる形にする
- **データ**：患者データを一切含まない（模式解剖のみ）
- **操作性**：横持ちで両手の親指が届く左右下部にボタンを置く
- **表示言語**：日本語

## 7. 制約・リスクと対策

最大のリスクはジャイロ操作の使い勝手で、初版の試用で最優先に確かめる。

| リスク | 影響 | 対策 |
| --- | --- | --- |
| Claudeの公開ページでは傾きセンサーが使えない | 傾き操作を試せない | スライダー操作を標準にした。傾き操作は配布方法を決めた後に実機で検証する |
| 傾けると画面自体も傾き、透視像が見にくい | 角度を決めながら像を確認できない | 「固定」ボタンで角度を止めてから画面を見直す流れにする |
| 横持ちでは傾きの軸が縦持ちと入れ替わる | 角度の向きが逆に感じられる | 横持ち固定とし、その向きで軸を定義する |
| 管球に近い背側の骨ほど大きく写り、斜位で速く動く | 椎体が手前にあるように錯覚しやすい | 骨を背側ほど濃く腹側ほど淡く描き、前後の手がかりにする |
| 模式解剖が実臨床と乖離する | 誤ったイメージが身につく | 将来版で実データ由来の解剖に移行する |
| スマホで画面が小さい・3D描画が重い | 透視像が見にくい、操作がもたつく | 実機で確認し、必要ならパネルの折りたたみや形状の簡略化を行う |
