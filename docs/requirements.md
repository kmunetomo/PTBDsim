# PTBD穿刺トレーニングアプリ 要件定義書

Oct 25, 2026（10/28 現行仕様に更新、CRA/CAU・呼吸・角度制約を追加） · @Kazuaki Munetomo

## 1. 目的と背景

放射線科専攻医が、X線透視下PTBDで「2Dの透視像から3Dの肝内胆管の位置を推測する」感覚を、被ばくなしにスマホで自習できるWebアプリを作る。

- 透視下穿刺は、投影像と体表の目印（肋骨・椎体）を頼りに3Dの胆管へ針を進める手技であり、その空間把握が難しい
- 実症例で経験できる数は限られ、練習のための透視は被ばくを伴う
- 本アプリの目的は空間イメージの形成であり、針を持つ手の感覚の訓練は対象外とする（将来、影絵式の実物模型で補う）

## 2. 対象者と利用場面

専攻医が指導医なしで1人で使うため、操作の分かりやすさと自動の答え合わせが要件の中心になる。

| 項目 | 内容 |
| --- | --- |
| 対象者 | 放射線科専攻医（PTBD未経験〜数例程度） |
| 利用場面 | 各自の自習（指導医不在を前提） |
| 端末 | スマホのWebブラウザ（インストール不要） |
| 学習目標 | 刺入点・刺入方向と胆管の立体的な位置関係を、透視像と斜位から推測できる |

## 4. 機能要件（初版）

初版の機能はF1〜F17（10/28夕：左バー廃止・刺入点ボタン廃止・肝内の段階制約・呼吸周期・肋骨の写りを更新）。10/28時点ですべて実装済み。

| ID | 機能 | 内容 |
| --- | --- | --- |
| F1 | 仮想透視画面 | 点線源からの投影（管球〜回転中心75 cm、管球〜検出器115 cm）。管球は背側・検出器は腹側。回転中心は正中・体厚の中央（頭尾は肝門よりやや尾側）、寝台移動は再現しない。視野は回転中心で横46 cm×縦16 cm以上を画面の縦横比に関わらず常に全景表示。表示するのは造影済み胆管・針・肋骨・椎体（椎弓根・横突起を含む）・胸骨・剣状突起・肝輪郭と心臓（うっすら）・体。体は上下端が見えない長い筒。門脈・肝動脈・肋軟骨は表示しない。患者の右が画面の左（放射線科の表示） |
| F2 | 写り方 | 乗算合成で減弱を表現。骨の吸収は通過する厚みに比例（断面の中心は濃く、ふちは淡い）、管球に近い背側ほどふちのぼけ幅が大きい。肋骨は肋骨頭（椎体の後外側）から始まる平たい帯で、側胸部までは同じ濃さ、腹側端に向かって細く（65%）・淡く（約半分）なる。剣状突起は胸骨より淡い。肝・心臓・体は厚みに比例して淡く写る |
| F3 | C-arm角度変更 | LAO/RAO（左右とも90°まで）と、ブルズアイを作るための控えめなCRA/CAU（±20°）。①透視を0.3秒長押ししてからドラッグ：左右でLAO/RAO（右へ＝LAO、画面幅で270°）、上下でCRA/CAU（上へ＝CRA、画面の高さで90°）。1回のドラッグでは最初に大きく動いた向きだけを変える。②長押し中は傾き操作でも動く（ひねり×3でLAO/RAO、起こす／寝かせる×1でCRA/CAU、寝かせるとCAU）。③「AP」で正面（頭尾も0°）、④「90°」でLAO/RAOを±90°に収まる側へ約0.9秒のアニメーションで直交する角度へ回す（CRA/CAUは保持）。離すと針の操作に戻る。縦スライダーは廃止 |
| F4 | 刺入点の選択 | 透視画像の短いタップのみ（タップした光線と体表の検出器側の交点。体の側面はRAO 90°にしてタップ）。プリセット・微調整ボタンは廃止。刺入点を変えても針の角度（水平・頭尾）は保持し、深さのみ0に戻す。針が刺さっている間は変更不可。直下に骨・軟骨があれば通知し、なくなれば通知をすぐ消す |
| F5 | 針の角度設定 | スライダー（水平・頭尾、各±60°）。「0°」ボタンで角度を0°に戻し、傾き操作の基準を今の姿勢に付け直す（抜針状態のみ有効）。表示する角度は呼吸で傾いた分も含めた実際の針の向き |
| F6 | 傾き操作 | スマホでは自動でオン（iPhoneは最初のタップで許可、HTTPSが必要）。横持ちで、画面を縦軸まわりにひねると針の水平、画面を起こす／寝かせると頭尾（寝かせると尾側）、いずれもスマホの傾きの1.5倍（40°傾けると60°）。透視の長押し中だけ、ひねりでC-armが回る（3倍）。水平・頭尾は個別に固定可。スライダーに触れている間はその対象の傾き操作を止め、離すと今の角度を基準に再開 |
| F7 | 針の前進・後退 | 右端の縦スライダー（上で刺入、0〜15 cm）。肋骨・胸骨・剣状突起・肋軟骨に当たるとそこで止まり、当たった構造を表示。当たり判定は見た目より甘い（肋骨は帯の中心部65%、肋軟骨は50%） |
| F8 | 穿刺判定 | 胆管内（枝名）／肝実質内／肝外を表示。胆管内では針と中枢側胆管のなす角（0°＝肝門側へまっすぐ、90°＝直交）も表示 |
| F9 | ターゲット | 設定で選んだ枝（B2〜B8、初期B3）の末梢寄り（枝の75%地点）に球を置く。直径5〜30 mm（初期7 mm）。透視では琥珀色の円で補助表示 |
| F10 | ガイド線 | 右パネルの「標的線」「延長線」でそれぞれON／OFF。標的線（刺入点→ターゲット中心、約2 px幅のシアンの破線）、延長線（針先からの白い点線） |
| F11 | 胆管の太さ | 末梢枝の径2〜12 mm（初期6 mm）。全枝を同じ比率で拡縮し、判定にも反映 |
| F12 | 3D答え合わせ | 肝・胆管・門脈・肝動脈・骨・胸骨／剣状突起／肋軟骨・心臓・針・X線の向き・ターゲット・ガイド線を表示。実際の左右で表示し、方向ラベル（R／L／頭／腹）付き。指で回転・拡大。結果パネルはタップで畳める |
| F13 | 抜針 | 深さと針の角度（水平・頭尾）を0に戻す。傾き操作中は今の姿勢を新しい基準にする |
| F14 | 体表図 | 透視の右上に、正面から見た体表（肋骨・肋軟骨・胸骨をうっすら）と刺入点、足側から見たC-armの向きを小さく表示。針の向きや胆管は描かない（答えにならないように） |
| F16 | 刺入後の角度制約 | 段階ごとに、その段階に入った時点の角度を中心に許容範囲を設け、重なる段階はすべて満たす。深さ2 cmまでは自由、それより深いと±5°。針先が肝に入ったら肝内の針の長さ（被膜〜針先）で、1 cm未満±5°、1〜3 cm±3°、3 cm以上は固定。引き戻して段階を抜けるとその制約は外れる。針を進めるだけでは角度は変わらない。数値は定数（`ANG_FREE`, `ANG_TOL`, `LIVER_TOL`）で調整可 |
| F17 | 呼吸性移動（Advanced） | 設定でオン。肝・胆管・門脈・肝動脈・ターゲットが頭尾に動く（12回/分＝5秒周期：吸気1.5秒・呼気1.5秒・呼気終末の休止2秒。振れ幅0.5〜3 cm、初期1.5 cm）。骨・体・心臓は動かない。針先が肝内にあると、肝内の針（被膜〜針先）の動きに最もよく合う向きへ、皮膚の刺入点を支点に傾く。右パネルの「息止め」で止まり、止める位置は毎回振れ幅の10〜50%の範囲で変わる |
| F15 | 補助の印 | シアン＝皮膚刺入点（刺入後のみ）、ピンク＝針先、針の手元に金属リング2つ（重なって中心に針先が見えるとブルズアイ）、琥珀＝ターゲット |

## 5. 画面構成と操作フロー

初版の画面は「穿刺」「答え合わせ」の2つ（症例選択は将来版）。横持ちで、左から次の3列に並ぶ。

- 左：透視（右上に体表図）。3D答え合わせもここに表示
- 右パネル：C-arm（角度表示・AP・90°）・針の角度（水平・頭尾・0°・固定）・判定・標的線／延長線・息止め（呼吸オン時のみ）・説明／設定／3Dで確認
- 右端：深さの縦スライダー（上で刺入）と抜針のみ（実機でスライダーを長く取るため）

1回の練習は次の順に進む。

1. 横持ちで開く。スマホでは傾き操作が自動でオンになる
2. 透視をタップして刺入点を選ぶ（体の側面はRAO 90°にしてタップ）
3. 必要に応じて「設定」からターゲット・胆管の太さを変え、右パネルのボタンでガイド線を表示する
4. 傾き操作かスライダーで針の角度を決める
5. C-armを回して（透視の長押しドラッグ・90°）、針の向きと胆管の前後関係を確認する。必要ならCRA/CAUも振ってブルズアイを作る（必要なら4に戻る）
6. 針を進め、判定（胆管内か、中枢側胆管との角度、当たった骨）を見る
7. 3D答え合わせで、針の軌跡と胆管・血管・骨の位置関係を確認する
8. 抜針して再挑戦する

## 6. 非機能要件

- **動作環境**：iPhoneのSafari、AndroidのChrome、PCのブラウザで動くこと。アプリのインストールは不要
- **画面の向き**：横持ちが前提。1画面（高さ100dvh）に収まり、スクロールしない
- **配信**：GitHub Pages（https://kmunetomo.github.io/PTBDsim/）。HTTPSなので傾き操作が使える
- **ソース管理**：GitHubの公開リポジトリ kmunetomo/PTBDsim（MITライセンス）。手元の正本は \~/dev/PTBDsim
- **構成**：1つのHTMLファイル（index.html）で完結、ビルドなし。three.js r128（cdnjs）とOrbitControls（jsdelivr）をCDNから読み込む
- **データ**：患者データを一切含まない（模式解剖のみ）。画面とREADMEに「教育用の試作・臨床判断に使わない」旨を明記
- **表示言語**：日本語

## 7. 制約・リスクと対策

主なリスクは傾き操作の精度と前後の錯視で、どちらも試作で対策済み。残る確認は実機での試用で行う。

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 重力に対する傾きでは「ひねり」を測れない | 意図と違う動き（ハンドル操作）に反応する | 端末の方位から長辺の向きを計算する方式に変更済み |
| 方位ベースの傾き操作は機種差・磁気の影響を受ける | 角度がじわじわずれる・揺れる | 「0°」ボタン・抜針で基準を付け直せる。スライダー操作で上書きできる |
| 投影像だけでは前後が分からなくなる（回る女性の錯視と同じ） | 針が胆管の手前か奥か判断できない | 斜位での確認を前提とし、実際の透視に近い拡大率・ぼけの差を再現。答えが分かってしまう補助（輪切りの模式図）は採用しない（8.1参照） |
| 模式解剖が実臨床と乖離する | 誤ったイメージが身につく | 将来版で実データ由来の解剖に移行する |
| スマホで画面が小さい・3D描画が重い | 透視像が見にくい、操作がもたつく | 操作部品を整理し透視を最大化済み。重さは実機で確認する |
